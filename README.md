# 파이썬 퀘스트

코딩을 처음 배우는 사람을 위한 **게임형 파이썬 시험 대비 학습 시스템**입니다.
수업 자료 「파이썬 및 필요 모듈 리뷰」 4개 강의의 모든 범위를 21개 스테이지와 4개 보스전으로 나눴습니다.

## 실행 방법

설치할 것이 없습니다. `index.html`을 브라우저로 열면 바로 시작됩니다.
(GitHub Pages로 배포하면 휴대폰에서도 주소만으로 열 수 있습니다: 저장소 Settings → Pages → Branch `main` / root)

기록(경험치, 별, 오답노트)은 브라우저의 localStorage에 저장됩니다.

## 구성

| 강의 | 월드 | 스테이지 |
| --- | --- | --- |
| 1강 | 파이썬 기초 마을 | 0 프롤로그 · 1 개요와 개발환경 · 2 구조와 입출력 · 3 변수와 숫자 · 4 문자열 · 5 연산자와 타입 변환 · 6 조건문 · 7 반복문 |
| 2강 | 자료구조의 숲 | 8 함수 · 9 리스트 · 10 튜플 · 11 사전과 집합 · 12 컬렉션 관리 |
| 3강 | 모듈의 성채 | 13 표준 모듈 · 14 파일 입출력 · 15 SQLite · 16 클래스 · 17 모듈과 패키지 |
| 4강 | 데이터 연구소 | 18 NumPy · 19 pandas · 20 matplotlib |

각 스테이지는 **배우기 → 도전 → 결과** 순서로 진행됩니다.

- **배우기**: 비유와 예제가 있는 카드. 코드의 `▶ 실행`으로 결과를, `한 줄씩 실행`으로 변수 변화를 볼 수 있습니다.
- **도전**: 객관식 · O/X · 출력 예측 · 빈칸 채우기 · 코드 순서 맞추기 · 짝 맞추기 (총 346문제). 하트 5개, 별 3개 평가, 콤보와 경험치.
- **보스전**: 강의마다 무작위 12문제, 제한 시간, 하트 3개.
- **요약노트**: 단원별 핵심과 시험 함정, 검색 가능.
- **오답노트**: 틀린 문제가 자동 저장되고 다시 맞히면 사라짐.
- **모의고사**: 강의 범위와 문항 수를 골라 실전처럼 풀고 단원별 분석 확인.
- **실습실**: 브라우저 안에서 파이썬 실행 (Pyodide, 첫 실행 시 인터넷 필요).
- **자유 모드**: 설정에서 켜면 모든 스테이지를 순서와 상관없이 열 수 있습니다.

## 파일 구조

```
index.html            진입점
assets/style.css      스타일 (#111111 · #333333 · #8d8d8d · #F5F5F5 · 포인트 #C3BDFF)
js/app.js             게임 엔진 (화면, 문제 유형, 저장, 실습실)
js/content/w1~w4.js   강의별 학습 카드와 문제
js/content/traces.js  '한 줄씩 실행' 데이터 (자동 생성)
tools/                콘텐츠 검증·생성 도구
```

## 콘텐츠를 고쳤다면

```bash
pip install numpy pandas
python3 tools/verify.py       # 모든 예제 코드와 정답을 실제 파이썬으로 실행해 검증
python3 tools/gen_traces.py   # trace: true 카드의 '한 줄씩 실행' 데이터 다시 생성
```
